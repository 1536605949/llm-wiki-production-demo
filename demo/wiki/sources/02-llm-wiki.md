## Source summary

# LLM-Wiki LLM-Wiki treats raw sources as immutable evidence and asks an LLM knowledge compiler to maintain a persistent Markdown Wiki. Ingest is not merely chunking plus embedding: new evidence may create source pages, update existing concept pages, add links, record provenance, and refactor previous synthesis. Query is Wiki-first. Search indexes are accelerators that can be rebuilt from the Markdown knowledge artifact.
