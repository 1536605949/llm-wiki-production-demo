This demo is an original educational/reference implementation inspired by the public LLM-Wiki pattern and current implementations. It does not copy their source code.

- Andrej Karpathy, **LLM Wiki** idea file (created 2026-04-04): https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f

- Community implementation docs, **LLM Wiki**: https://llmwiki.cc/docs

Key pattern retained here: human-owned immutable raw sources, LLM-maintained Markdown wiki, co-evolved schema/AGENTS.md, and the three operations ingest/query/lint.
