# Knowledge Compounding in LLM-Wiki

Knowledge compounding means that later evidence can revise an already-existing durable concept page. The system
does not need to rediscover the same synthesis from raw chunks on every query.

A valuable query result can be explicitly promoted back into the Wiki through save-back. Lint then checks the
long-lived knowledge artifact for broken links, missing provenance, orphan pages, contradictions, and staleness.

This source again discusses LLM-Wiki, so ingesting it should update the existing LLM-Wiki concept page and add a
second provenance source.
